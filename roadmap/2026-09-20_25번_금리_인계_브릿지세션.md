# 인계 — 25번 금리 확인 (브릿지 있는 세션 / 대표님 손)

**목표**: 「2026년도 중소기업 정책자금 융자계획 공고」의 **융자조건** 표에서 청년전용창업자금 금리를 확정한다.

## 0. 왜 새 원격 세션으로는 안 되나

이 계정의 원격 환경은 **`Default - trusted network access` 하나뿐**이다(env 조회 2026-09-20). 새 세션을 띄워도 **같은 환경 = 같은 egress 정책**이라 `go.kr`은 그대로 막힌다. 그래서 인계 대상은 **브릿지(GAS)가 있는 쪽**이다.

## 1. 권장 경로 — GAS가 받아서 드라이브에 놓는다 (⭐ 가장 빠름)

Apps Script는 **구글 서버에서** 나가므로 이 환경의 차단과 무관하다. 파일이 드라이브에 놓이면 **이 세션에서 드라이브 커넥터로 바로 읽을 수 있다**(PDF 지원). 즉 대표님이 아래 한 번만 돌려 주시면 **확인은 제가 마무리한다.**

Apps Script 편집기에 임시 함수로 붙여 1회 실행:

```javascript
function fetchPolicyFundNotice() {
  // 기업마당 「2026년도 중소기업 정책자금 융자계획 공고」 첨부파일
  var url = 'https://www.bizinfo.go.kr/cmm/fms/getImageFile.do'
          + '?atchFileId=FILE_000000000739124&fileSn=0';
  var res = UrlFetchApp.fetch(url, { muteHttpExceptions: true, followRedirects: true });
  Logger.log('http=' + res.getResponseCode() + ' bytes=' + res.getContent().length);
  var blob = res.getBlob().setName('공고_2026_정책자금_융자계획.pdf');
  var file = DriveApp.createFile(blob);          // 내 드라이브 루트에 생성
  Logger.log('fileId=' + file.getId() + ' type=' + file.getMimeType());
}
```

- 로그의 `http=200`·`bytes` 가 0이 아닌지 확인
- `type` 이 `application/pdf` 가 아니면 HTML 안내 페이지를 받은 것 → 3번 경로로
- 끝나면 **파일명만** 알려 주시면 된다(ID는 필요 없다 — 드라이브 검색으로 찾는다)

이 함수는 **읽기 전용 외부 호출 + 드라이브 파일 생성 1건**이다. 시트·페이지를 건드리지 않고, 쓰고 나면 지워도 된다.

## 2. 무엇을 뽑아야 하나 (제가 PDF에서 찾을 것)

- **융자조건** 표의 자금종류별 금리 행 — **청년전용창업자금**이 별도 행으로 있는지
- 고정/변동 표기, 정책자금 기준금리 연동 여부, 가감금리
- 융자한도(운전·시설), 융자기간, 대표자 연령·업력 요건
- 공고 번호·공고일 (근거 문서 칸에 적을 값)

## 3. 대안 경로

- **콜센터 1811-3655** — 한 줄 질문: 「청년전용창업자금 2026년 금리가 고정 2.5%인지, 창업기반지원자금 일반 트랙과 다른지」. 통화 결과를 알려 주시면 `근거 문서` 칸을 「콜센터 확인 2026-XX-XX」로 적는다
- **브라우저 있는 로컬 세션** — 공고 PDF를 열어 융자조건 표만 캡처/텍스트로 저장 → 드라이브에 두면 제가 읽는다
- **12월 사전상담**(A트랙 60번) — 어차피 예약이 필요하니 같이 질의. 단, 그때까지 25번은 「미확인」으로 둔다

## 4. 확정되면 바뀌는 것

| 대상 | 값 |
| :-- | :-- |
| 100억 탭 25번 `목표·내용` | 트랙 명시 + 확정 금리 |
| 100억 탭 25번 `근거 문서` | 공고명 §융자조건 또는 콜센터 확인일 |
| 로드맵(미래) 청년전용창업자금 행 `주요 구현 항목` | 상환 시뮬의 입력값 |
| `2026-09-20_25번_금리_확인기록.md` | 가설 A/B/C 중 판정 + 실패 기록 종결 |

## 5. 현재 상태 (인계 시점)

- 공고 원문 확인 **실패** — 5경로 전부 egress 차단
- 시트 25번은 **금리 미확인 · 트랙 미특정**이 가장 정확한 상태. 시트값(3.0~3.5%)을 오류로 단정할 근거는 없다
- 라이브 시트 쓰기 **0**
