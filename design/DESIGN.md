## 3. 타이포그래피

- 본문 산세리프(테마 상속). 테마 twentytwentyfour가 h1~h6를 Cardo(세리프)로 강제하므로 오랑 컨테이너 안 `h1~h6·button·input`에 `font-family:inherit!important` 필수(시트 97행).
- 오랑Pick 대주제 h2: 섹션번호 + 오렌지 아이브로우 + 31px 타이틀 + 상단 룰. 소제 h3: 주황 좌측 바(시트 101행).
- 제목에 결론을 넣지 않는다. "~이다/~입니다" 종결 금지(102행). 소제목은 함축(103행).
- 문단 간격 데스크톱 40px, 기본의 두 배(107행). 이미지·도표 위아래 64px(108행).
- 한글 UI 문구: 간결·존대·행동 유도형. 내부 용어(유치부 등) 노출 금지(제4조).
- **타입 램프(수치 스케일)는 아직 문서화돼 있지 않다.** 레퍼런스 대조 1순위 공백.

## 4. 형태 (Shape)

| 요소 | 라운드 |
| :-- | :-- |
| 필(알약·칩·배지) | `9999px` |
| 카드 | `16~18px` |
| 버튼 | `9~12px` |

그림자는 부드러운 단일 계열. 베젤·포커스: 기본 outline 제거, `:focus-visible`만 브랜드 아웃라인, `-webkit-tap-highlight-color:transparent`.

**간격 스케일(4/8pt 등)은 문서화돼 있지 않다.** 레퍼런스 대조 2순위 공백.

## 5. 모션

- 등장 `0.25~0.6s cubic-bezier(.16,1,.3,1)`.
- 목록은 **순차 등장**, 항목당 `0.06~0.09s`.
- 무한 반복 네온·펄스는 안내 말풍선 1곳 외 금지. 예외: New 배지 점 깜빡임(139행), 오랑Pick 버튼 로딩 시 테두리 한 바퀴(137행), "읽는 중" 진행 애니(112행).
- 스크롤 등장에서 `position:fixed` 요소 제외 + 미등장 안전장치 인터벌(제5조 6항).
- 랜딩: 원문이 잠깐 보였다 바뀌는 FOUC 불허. 전로딩으로 가린 뒤 위에서부터 순차 등장(124행).
- 주기 실행 코드는 멱등(제5조 8항). 상태 같으면 쓰지 않는다.

## 7. 반응형

4단계: 와이드(3열) → 사이드 접힘 → 하단 탭바 → 컴팩트. 가독성이 무너지는 폭에서는 **표현을 강등**(막대→점, 표로 전환). 캘린더 ≤1180px 월간뷰 = 점(무기능). 풀블리드는 `100vw` 금지, 테마 래퍼 `max-width:none`으로.

## 8. 금지 (Don't)

- 오렌지 바탕 전면. 발바닥 임의 작화.
- 툴바 흐림(`opacity:.45`). 준비중 딱지의 영구화.
- 로그인 이동. 네이티브 confirm/alert.
- em dash. 읽는 시간 등 장식 수치. 결론형 제목.
- 형광펜·밑줄·볼드 남발(섹션당 1~2곳).
- 무한 펄스(예외 3곳 외).
- 잔상. 낙관적 UI(서버 확정 전 최종 상태).
- `overflow-x:hidden`(sticky 죽음, `clip` 사용).

## 9. 레퍼런스 대조 시 채워야 할 공백 (우선순위)

1. **타입 램프** 수치(H1~캡션 6~7단 + line-height).
2. **간격 스케일**(4/8pt) + 카드 내부 패딩 표준.
3. **스켈레톤/shimmer 규격**(카드형·목록형·패널형).
4. **빈 상태** 3종(검색 0건 · 비로그인 · 준비중)의 일러스트/문구 틀.
5. **surface 단계**(흰 배경 위 카드·패널·오버레이 3단 톤).
6. 폼 컴포넌트(입력·검증·비활성·오류 말풍선) 통일 규격. 구독·결제 화면 신설 시 즉시 필요.
