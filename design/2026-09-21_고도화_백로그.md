## 1. 메인 피드 `/orangpro/`

**현행**: 상단툴바 → 좌측툴바(역할 탭·필터 아코디언) → 피드 카드(순차 등장) → 우측 레일 → 하단 nav. 온보딩 게이트는 메인에만. 필터: 키워드·정렬·기간·발행기관·이슈 중요도(80+)·역할 탭 + 오랑Pick 토글.

**조사 질의**
```
Nicelydone/Lazyweb: "content feed with sidebar filters and role tabs" · "filter chips active state" · "empty search results state" · "skeleton loading card list" 각 5장.
Inspo: recommend(brief="education news intelligence feed, white bg, orange accent, card list with agency chips and impact score, Korean", pageType="dashboard").
Inspo: find_by_color("#f97316", tolerance=낮게) → 오렌지 포인트 사이트 5곳의 get_design_system.
Refero: refero_search("clean information-dense SaaS feed, warm accent, generous whitespace") → refero_design_md 2개.
```

**뽑아 올 것**: 필터 활성 상태 표현(아이콘/체크 우선, 제3조 2항) · 카드 밀도 2단(컴팩트/편안) · 스켈레톤 규격 · 검색 0건 빈 상태 · "+N건 더보기" 인셀 확장 패턴 · 카드 내부 간격 스케일.

**불변**: 툴바 4종 · 로고 바 · 게이트(블러+중앙 카드) · New 배지 규격 · impact 80 기준 · 오랑Pick 카드 규격(135행) · 상세 패널 도르래(140행) · iframe 구조(부모가 DOM 교정, 첫 iframe 잡기 금지).

**검증**: 로그인/로그아웃 양쪽 · 필터 조합 3개 실클릭 결과 건수 대조 · 새 글 카드에 New 배지(비동기 렌더 표식 함정) · 콘솔 0 · ≤782px 하단 탭바 · 크롤 경로(`/orangpro/news/` 정적 목록)는 건드리지 않았는지.

## 2. 구독·결제 화면 (신설)

**현행**: 없음. 로드맵(미래)에 "유료 구독 예정"만 있다. 결제 PG·플랜 구성은 미정이므로 **UI 뼈대와 상태 설계**까지가 이번 범위다.

**조사 질의**
```
Mobbin/Nicelydone: "pricing page 2 tiers" · "subscription checkout single page" · "payment form with card input validation" · "plan comparison table mobile" 각 6장.
Lazyweb: lazyweb_search_experiments("pricing page") → A/B 실험 결과(전환율 근거) 5건.
Inspo: find_examples_for_macrostructure("Pricing") + recommend(brief="Korean edtech subscription, 2 plans, monthly/yearly toggle, orange accent, trust badges").
Refero: refero_search("pricing, minimal, warm accent, clear hierarchy") → DESIGN.md.
```

**뽑아 올 것**: 플랜 카드 위계(추천 플랜 강조 1곳만) · 월/연 토글 · 결제 폼 입력 검증·오류 말풍선·처리중 잠금(제3조 9항 낙관적 UI 금지) · 신뢰 요소 배치(사업자정보·환불 정책 한 줄, 제4조 5항) · 성공/실패 상태 화면.

**불변**: 로그인 게이트 = 그 자리 모달 · 확인창 커스텀 · 브랜드 토큰 · 페이지 제목 규칙(Rank Math `rank_math_title`로 설정, 사이트명 접미사 금지) · 새 페이지 체크리스트(제2조 1~13항 전부).

**검증**: 폼 Enter/Tab만으로 완주(제3조 5항) · 처리중 이중 제출 불가 · 오류 문구에 기술 용어 0 · 비로그인 진입 시 게이트 · 정적 HTML에 플랜 설명 문자 존재(제21조).

## 8. 빈 상태·로딩·오류 공통 (전역 블록 신설)

제1법이 "누락 1순위"로 지목한 항목이다. 화면별이 아니라 **전역 footer 신규 블록 1개**로 만든다(경로 가드 + 마커 필수, 제7조 12항).

**조사 질의**
